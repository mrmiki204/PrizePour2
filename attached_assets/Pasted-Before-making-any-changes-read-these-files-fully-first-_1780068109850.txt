URGENT BUG:

“No giveaways yet.”

This is wrong.

Admin should ALWAYS show all draws, including:

* active
* inactive
* hidden
* visible
* paused
* ended
* previous
* test
* seeded draws

The hide button should ONLY control public website visibility.

## Root Cause To Investigate

Do not guess. Inspect the code.

Check:

1. Admin draw fetch endpoint/query.
2. Homepage/public draw fetch endpoint/query.
3. Any shared filtering helper.
4. The hide/show toggle mutation.
5. Any frontend filtering in the admin dashboard.
6. Whether admin is accidentally using the public filtered endpoint.
7. Whether hidden draws are being removed from state after toggle.
