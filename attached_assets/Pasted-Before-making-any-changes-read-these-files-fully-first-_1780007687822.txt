Task:
Add lightweight analytics and conversion tracking to PrizePour.

Goal:
Understand visitor behaviour before launch without enabling payments.

Track:

* which draws users click most
* which hero CTAs get clicked
* which collections get most interest
* waitlist signup conversions
* basic visitor/page activity

Do NOT add payment tracking. Do NOT enable checkout.

---

## Stage 1 — Analytics Data Model

Create a lightweight analytics table/model.

Suggested table:
`analytics_events`

Fields:

* `id`
* `eventType`
* `eventName`
* `drawSlug` optional
* `pagePath` optional
* `metadata` optional JSON/text
* `createdAt`

Suggested event types:

* `page_view`
* `hero_cta_click`
* `draw_click`
* `explore_collection_click`
* `waitlist_started`
* `waitlist_completed`
* `waitlist_failed`
* `waitlist_duplicate`

Requirements:

* safe DB insert
* no sensitive personal data
* no payment data
* no breaking existing DB
* idempotent migration

---

## Stage 2 — Tracking API

Create a public analytics POST endpoint.

Requirements:

* accepts safe event payloads only
* validates allowed event types
* rejects unknown/unsafe events
* does not expose analytics data publicly
* does not log secrets
* handles errors silently so analytics never breaks the frontend
* optional basic rate-limit/spam protection if easy
